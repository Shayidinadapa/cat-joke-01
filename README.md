# The One-Line Cat Joke That Lands

Entry for the [make.fun bounty "The One-Line Cat Joke That Lands"](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

`main.ts` writes a single one-line cat joke (under 200 characters) to `/output/entry.txt`, validates it against the competition gate (1–200 characters, one line, not only white space, about a cat), then reads it back and throws on any mismatch.

Run it with:

```sh
node main.ts
```
